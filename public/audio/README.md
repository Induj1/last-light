# Local audio

These nine PCM WAV files are original synthesized tones generated by `scripts/generate-audio.mjs`. No third-party samples or network services are used. The frontend serves them from `/audio/` and unlocks browser audio after the player's first interaction.

`warning`, `save`, `waste`, `fail`, `critical`, `storage`, `countdown`, `result-success`, and `result-fail` correspond to the game's named events. Each is mono, 22,050 Hz, signed 16-bit PCM. Adjust volume at the laptop and in the game; the short cues are designed to leave room for conversation.

Regenerate with `node scripts/generate-audio.mjs` from the project root. The result cues contain no leading silence; the frontend schedules the pause before playing them.
